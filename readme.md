# Anyplace

Minimal spatial note-taking app. Click anywhere to write. No build step, no dependencies.

## Quick Start

Open `index.html` in a browser. That's it.

Or serve locally:
```bash
python3 -m http.server 8080
```

## Features

- Click anywhere on canvas to create a note
- Drag notes to reposition
- Cmd/Ctrl+B for bold, Cmd/Ctrl+I for italic
- Multiple documents with sidebar navigation
- Search documents
- Dark/light theme toggle
- Auto-save to localStorage
